# Using GitHub Education and Copilot in This Course

GitHub Education is the main student pathway for getting GitHub Copilot benefits in this course. You can use GitHub Education to verify your student status, activate student benefits, and start using Copilot in VS Code.

## What GitHub Education is

GitHub Education is GitHub's student and educator program. It gives eligible students access to education-focused benefits and tools such as:

- GitHub Copilot student access
- GitHub Codespaces benefits
- the Student Developer Pack
- GitHub Classroom-related workflows
- other student resources and offers

In this course, the main reason most students will care about GitHub Education is Copilot access.

## Why sign up

Students usually care about a few practical benefits:

- Free access to GitHub Copilot for verified students
- Access to additional student developer tools and offers
- Easier participation in GitHub-based course workflows
- Optional extras such as Codespaces, if you need them

If the course allows AI-assisted coding, GitHub Education can make it much easier to get started with Copilot using your existing GitHub account.

## Who qualifies

Based on the current GitHub Education guidance, students generally need to meet these requirements:

- You are at least 13 years old.
- You have a personal GitHub account.
- You are enrolled in a degree-granting or diploma-granting educational program.
- You can provide proof of current student status if GitHub asks for it.

GitHub reviews eligibility using the information in your application and may ask for supporting documents if your status cannot be confirmed automatically.

## What you need before applying

Before you apply, gather the following:

- A personal GitHub account
- Your academic or school email address
- Proof of current student status, if needed

Examples of proof that may be accepted include:

- a school ID showing a current date or term
- a class schedule
- a transcript
- an enrollment letter

Helpful details from the GitHub docs:

- Make sure any uploaded proof is clear, readable, and current.
- Blurry, cropped, or undated documents may be rejected.
- Some schools require you to apply with your academic email.
- If you enter an academic email, use lowercase and avoid plus-addressing.

## How to apply for GitHub Education

Use the official GitHub Education student page and benefits settings flow:

1. Sign in to your personal GitHub account.
2. Go to the GitHub Education student page or directly to the education benefits settings page.
3. Start an application for GitHub Education.
4. Fill out the form carefully.
5. Add your academic email if required.
6. Upload proof of student status if GitHub asks for it.
7. Submit the application.
8. Wait for GitHub to review the request.
9. After approval, return to the GitHub Education portal or benefits page.

Practical advice:

- Use the same personal GitHub account you plan to keep for course work.
- Do not create multiple accounts unless you have a strong reason.
- If you already have more than one account, be careful about which account you keep as your long-term student account.

## How to activate Copilot Student

After your student status is verified:

1. Go back to the GitHub Education benefits page.
2. Look for student developer resources and the Copilot benefit.
3. Use the `Learn more` or activation flow for Copilot Student.
4. Follow the prompts to enable Copilot on your account.
5. Review any Copilot settings or policies GitHub asks you to confirm.

If you are not yet verified, GitHub may send you back through the Education verification process before Copilot can be activated.

## How to start using Copilot

In this course, VS Code is the main place students will use Copilot.

Basic setup:

1. Open VS Code.
2. Open the Extensions view.
3. Install the `GitHub Copilot Chat` extension.
4. Sign in to GitHub inside VS Code using the same account that received GitHub Education benefits.
5. Open the course repository folder in VS Code.
6. Make sure the correct Python interpreter is selected.
7. Confirm Copilot suggestions appear while you work.

Good first uses of Copilot in this course:

- asking for code explanations
- getting syntax help
- debugging error messages
- generating small amounts of boilerplate

Do not to start with "write my whole assignment." Instead:

- open the correct course folder
- understand the problem first
- ask Copilot for small, inspectable help
- test the result
- follow the course AI-use policy

- ``As we work hard and smart, AI can be a valuable tool to enhance but not replace our own efforts.''

## Common problems and fixes

### Your application was denied because the documents were unclear

What to try:

- Recheck the uploaded proof.
- Make sure the image or document is readable.
- Make sure it includes a current date, term, or other current enrollment evidence.
- Reapply with clearer documentation if appropriate.

### Your school requires an academic email

What to try:

- Use your school-issued email if your institution expects that.
- Enter the email in lowercase.
- Avoid plus-addressing such as `name+school@example.edu`.

### Your school email domain is not recognized

What to try:

- Continue through the application and provide supporting documents if GitHub requests them.
- Use your academic email plus current proof of enrollment.
- Ask GitHub Education support if the domain problem blocks the application.

### Your academic email is already tied to another account

What to try:

- Make sure you are using the GitHub account you want to keep long term.
- Benefits should be attached to the personal account you retain for your coursework.
- If your email is connected to the wrong account, resolve that account issue before reapplying if possible.

### You are not yet verified, so Copilot is unavailable

What to try:

- Check whether your GitHub Education application is still under review.
- Confirm that your account actually shows approved student benefits.
- Return to the Education benefits page after approval and activate Copilot from there.

### You signed into the wrong GitHub account in VS Code

What to try:

- Check which GitHub account VS Code is using.
- Sign out if necessary.
- Sign back in with the same GitHub account that has your student benefits.

### The Copilot extension is installed but not active

What to try:

- Make sure the `GitHub Copilot` extension is installed.
- Reload or restart VS Code.
- Confirm you are signed in.
- Check whether Copilot is enabled for your account.

### Renewal or eligibility questions

What to know:

- GitHub reevaluates student eligibility regularly.
- The current docs note that reevaluation happens monthly.
- If your benefits expire and you are still eligible, you may need to renew or reverify.

## When to ask for help

Ask for help early if the process stalls. When you ask, include:

- your GitHub username
- whether the issue is Education verification or Copilot activation
- the exact step where it failed
- whether there is an academic email or school-domain problem
- the full error message as text
- screenshots if the message is hard to describe

That information makes it much easier for someone to help you quickly.
